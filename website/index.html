常见问题

快速了解默认软件设置、系统右键菜单与扩展格式支持。

在 macOS 上如何把 QPack 设为默认解压缩软件？

在访达（Finder）中选中任意 .zip（或 .7z / .rar）文件，按 ⌘I 打开「显示简介」→ 展开「打开方式」→ 选择 QPack → 点击「全部更改…」即可。此后双击该类压缩包都会直接使用 QPack 打开预览或智能解压。

Windows 11 右键菜单里在哪里可以看到 QPack？

首次启动 QPack 会自动向当前用户注册表写入右键菜单（无需管理员权限）。在 Windows 11 上，右键文件或文件夹后点击底部 「显示更多选项」，或直接按住 Shift + 鼠标右键 即可看到「使用 QPack 智能解压」与「使用 QPack 压缩为 ZIP」。

如何开启 RAR / ISO / DMG 全格式解压支持？

macOS 用户在终端执行 brew install sevenzip；Windows 用户安装 7-Zip 并确保 7z.exe 在系统 PATH 中。QPack 会自动探测并启用 7zz 扩展引擎，无需手动配置路径。
